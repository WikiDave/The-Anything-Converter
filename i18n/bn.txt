সব ডাউনলোড ও সংস্করণ
1. .msi ফাইল ডাউনলোড করে ডাবল-ক্লিক করুন
2. 'windows আপনার pc সুরক্ষিত করেছে'? → আরও তথ্য → তবুও চালান
3. স্টার্ট মেনু থেকে 'Anything Converter' খুলুন; এটি ব্রাউজারে খুলবে
1. .dmg খুলে অ্যাপটি Applications-এ টেনে আনুন
2. অ্যাপ খুলুন; সতর্কবার্তা এলে বন্ধ করুন
3. সিস্টেম সেটিংস → গোপনীয়তা ও নিরাপত্তা → নিচে 'তবুও খুলুন'
// কোন mac? apple মেনু → এই mac সম্পর্কে: 'চিপ apple m…' = এটি
// কোন mac? apple মেনু → এই mac সম্পর্কে: 'প্রসেসর intel' = এটি
1. .deb ফাইল ডাউনলোড করে খুলুন (সফটওয়্যার ইনস্টল)
অথবা টার্মিনালে: sudo apt install ./AnythingConverter-Linux.deb
2. মেনু থেকে 'Anything Converter' খুলুন
1. .AppImage ফাইল ডাউনলোড করুন
2. রাইট-ক্লিক → প্রপার্টিজ → 'প্রোগ্রাম হিসেবে চালাতে দিন' চালু করুন
3. শুরু করতে ডাবল-ক্লিক করুন
1. ফোনে .apk ফাইল ডাউনলোড করুন
2. খুলুন; ব্রাউজারকে 'অজানা অ্যাপ ইনস্টল' করার অনুমতি দিন
3. 'Converter' খুলুন; সেভ করা ফাইল Downloads/Anything Converter-এ থাকে
// youtube লিংক আর টরেন্ট শুধু কম্পিউটারে চলে
apple অ্যাপ স্টোরের বাইরের অ্যাপ অনুমতি দেয় না; ওয়েব অ্যাপ ব্যবহার করুন:
1. এই পেজটি safari-তে খুলুন
2. শেয়ার (তীরসহ বাক্স) চাপুন → হোম স্ক্রিনে যোগ করুন → যোগ করুন
3. হোম স্ক্রিন থেকে 'Converter' খুলুন
